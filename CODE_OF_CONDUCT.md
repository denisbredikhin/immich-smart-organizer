# Code of Conduct

We aim to keep this project welcoming, constructive, and focused on improving the software.

## Expected behavior

- Be respectful and considerate.
- Discuss technical ideas in good faith and critique proposals rather than people.
- Give useful, specific feedback and accept reasonable corrections.
- Respect privacy; do not post API keys, private server details, or personal media.

## Unacceptable behavior

Harassment, insults, discriminatory language, threats, deliberate disruption, and publishing another person's private information are not acceptable.

## Enforcement

Project maintainers may edit or remove unacceptable content and may temporarily or permanently exclude contributors whose behavior harms the community. Report concerns privately to the repository owner through GitHub. Maintainers will handle reports as discreetly as practical.
